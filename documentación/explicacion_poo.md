# Aplicación de Programación Orientada a Objetos

## Proyecto

**Gestor Inteligente de Clientes (GIC)**

El Gestor Inteligente de Clientes es una aplicación desarrollada en Python para registrar, consultar, editar y eliminar clientes. El sistema diferencia entre clientes regulares, premium y corporativos, utiliza validaciones, manejo de errores, archivos JSON y CSV, una base de datos SQLite, registro de actividades e interfaz gráfica con Tkinter.

## Programación Orientada a Objetos

La Programación Orientada a Objetos es un paradigma que permite representar elementos de un sistema mediante clases y objetos. Una clase actúa como un molde que define atributos y métodos, mientras que un objeto es una instancia concreta creada a partir de esa clase.

En este proyecto, la clase `Cliente` representa el modelo general de una persona o empresa registrada en el sistema. A partir de ella se crean diferentes tipos de clientes especializados.
